# Restaurant Assignment

This project is a restaurant management system with a backend API and a customer-facing UI.

## Project Structure

- `backend/`: Contains the Node.js Express API.
- `customer-ui/`: Contains the React-based customer user interface.

Further instructions for setting up and running the project will be added here.

## Technologies Used

### Backend (Node.js/Express)
- **Express.js**: Web application framework
- **Mongoose**: MongoDB object modeling tool
- **bcryptjs**: For password hashing
- **jsonwebtoken**: For authentication with JSON Web Tokens
- **dotenv**: For loading environment variables
- **cors**: For enabling Cross-Origin Resource Sharing
- **helmet**: For securing Express apps with various HTTP headers
- **express-rate-limit**: For basic rate-limiting middleware
- **zod**: For schema validation
- **nodemon**: For automatically restarting the node application when file changes are detected (development)

### Customer UI (React/Vite)
- **React**: JavaScript library for building user interfaces
- **Vite**: Next-generation frontend tooling (development)
- **Tailwind CSS**: Utility-first CSS framework
- **Lucide React**: Beautiful & consistent icon toolkit
- **Oxlint**: A JavaScript linter (development)
